# PSPdisp

PSPdisp turns a PSP into a second display of the computer: the PSP shows a virtual display, plays the desktop sound, and its buttons drive a virtual gamepad, keyboard or mouse, over USB or WLAN.
It's a rewrite of [PSPdisp by JJS](http://jjs.at/software/pspdisp.html) (2008-2015), whose PSP app (`psp/source`) talks to a new desktop app.
